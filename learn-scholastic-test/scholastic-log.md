## **Tipe-tipe Tes Bakat Skolastik (TBS/SBK) LPDP**


| Kelompok                     | Tipe soal               | Contoh yang sering muncul                               |
| ---------------------------- | ----------------------- | ------------------------------------------------------- |
| **1. Verbal**                | Sinonim                 | persamaan kata                                          |
|                              | Antonim                 | lawan kata                                              |
|                              | Analogi kata            | hubungan kata, misalnya*dokter : pasien = guru : murid* |
|                              | Pemahaman bacaan        | ide pokok, kesimpulan, pernyataan benar/salah           |
|                              | Penalaran verbal        | memahami argumen, asumsi, inferensi                     |
| **2. Kuantitatif / Numerik** | Deret angka             | pola bilangan                                           |
|                              | Aritmetika dasar        | tambah, kurang, kali, bagi                              |
|                              | Pecahan & desimal       | operasi pecahan/desimal                                 |
|                              | Persentase              | diskon, kenaikan, penurunan                             |
|                              | Perbandingan            | rasio, proporsi, skala                                  |
|                              | Aljabar sederhana       | persamaan satu/dua variabel                             |
|                              | Soal cerita             | umur, jarak-waktu-kecepatan, untung-rugi, pekerjaan     |
| **3. Penalaran / Logika**    | Silogisme               | semua A adalah B, sebagian B adalah C                   |
|                              | Logika analitis         | urutan duduk, jadwal, posisi, ranking                   |
|                              | Penalaran pola          | pola angka, huruf, atau bentuk                          |
|                              | Penarikan kesimpulan    | menentukan kesimpulan paling tepat                      |
|                              | Sebab-akibat            | hubungan logis antar pernyataan                         |
|                              | Analisis data sederhana | tabel, grafik, diagram                                  |

Versi ringkasnya:

**TBS LPDP = Verbal + Numerik + Logika/Penalaran.**

Kalau kamu mau latihan dari nol, urutannya paling enak:

1. **Numerik dasar**: persentase, rasio, deret, aljabar.
2. **Logika dasar**: silogisme dan logika posisi.
3. **Verbal**: analogi, sinonim, antonim, bacaan.
4. **Campuran timed test**: latihan dengan batas waktu.

Yang paling mirip dengan CPNS adalah bagian **TIU**, terutama **verbal, numerik, dan logika**.
